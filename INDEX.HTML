Component Explanations

🏙️
ENV SUMO / TraCI
SUMO (Simulation of Urban Mobility) is an open-source traffic simulator. TraCI (Traffic Control Interface) is its Python API, allowing the DQL agent to read vehicle data and issue signal-phase commands in real time each simulation step.
📡
SIG State Vector (s)
At every time step the environment reports the agent's observation: per-lane queue lengths (number of vehicles waiting) and a one-hot encoding of the active traffic-light phase. This compact vector fully describes what the agent can observe.
🏆
SIG Reward Signal (r)
The reward is the negative change in cumulative vehicle wait time (−Δ wait). Reducing total waiting earns a positive reward; increasing it penalises the agent. This directly aligns the agent's goal with minimising intersection congestion.
🧠
AGENT Deep Q-Network
A neural network approximates Q(s, a) — the expected cumulative reward for taking action a in state s. An ε-greedy policy balances exploration vs exploitation. Weights are updated via the Bellman equation: Q(s,a) ← r + γ·max Q(s′,a′).
💾
AGENT Replay Memory
Each transition (s, a, r, s′) is stored in a circular buffer. Training samples a random mini-batch, breaking the temporal correlation between consecutive steps. This is essential for stable gradient-descent learning in an RL setting.
🎯
AGENT Target Network
A frozen copy of the Q-network provides stable Bellman targets during training. Its weights are periodically copied from the live network (every N steps). Without this, the target would shift every update, causing training instability or divergence.
